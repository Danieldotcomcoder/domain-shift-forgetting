## Question and claim boundary

Does replacing internal RMSNorm through a calibrated TaperNorm schedule increase persistent held-out web deterioration after a web-to-Python switch, relative to continuing web training?

H1 concerns the complete training intervention, including its taper history. It does not isolate sample dependence from all optimization effects, establish a gain-mismatch mechanism, or describe normalization-free transformers generally. The final RMSNorm stays active.

The pilot selects whether further work is worth funding. It is not the final confirmatory experiment; reserved test data stay unopened.

## Fixed design

Use 6 layers, hidden width 256, 4 attention heads of size 64, GELU MLP width 1,024, learned absolute positions, context 512, tied 50,257-token GPT-2 embeddings/output weights, no linear biases, no dropout. Approximately 17.7M parameters including embeddings; record the actual count. Keep this model size fixed; remove the discretionary 34M alternative.

Primary conditions: RMS (no auxiliary loss) and Taper-minus (no auxiliary loss). Optional secondary condition: Taper-plus with the scale auxiliary loss. All keep the final RMSNorm.

Use three paired seed groups: 101, 102 and 103. Pair initialization tensors and web/code order within each group. Explicitly copy a canonical base state into each condition; matching random seeds alone is insufficient when modules consume RNG differently.

Every condition trains one web prefix and then two branches: continued web and continued Python. Branch checkpoints include identical optimizer moments and RNG/data state within the condition. Different normalization conditions have different trained prefixes.

No LoRA, instruction tuning, RL, replay, correction multiplier, optimizer reset or LR restart. No outcome-dependent tuning.

## Optimizer and initialization

AdamW: learning rate peak 0.0006; betas (0.9, 0.95); epsilon 1e-8. Matrix weight decay 0.1; every gain vector has zero decay. Global gradient clipping 1.0 once after accumulation. BF16 autocast, FP32 master parameters/moments and FP32 norm/EMA reductions.

Initialize matrix and embedding weights with normal standard deviation 0.02, residual output projections with 0.02 divided by sqrt(12), and gains at one. Effective update batch: 32 sequences × 512 supervised labels = 16,384 tokens. Initial microbatch 8, accumulation 4; if memory requires a change, preserve effective batch and freeze the choice before runs.

Use optimizer update numbers u=1…15,260. LR at u≤305 is 0.0006×u/305. Subsequently:

$$
\eta(u)=0.00006+\tfrac12(0.0006-0.00006)\left[1+\cos\left(\pi\frac{u-305}{15260-305}\right)\right].
$$

Continue this global clock after branching. Save completed-update counts, not ambiguous epoch numbers.

## Internal TaperNorm

Implement the published RMS-variant operator and calibration, with the explicitly changed timing below:

$$
r(h)=\sqrt{\|h\|_2^2/d+10^{-6}}
$$

$$
y=g\,(h/r(h))\odot\gamma+(1-g)c\,h\odot\widetilde\gamma.
$$

During the first 763 updates, g=1. Compute gamma-weighted numerator and denominator means over all microbatches in an effective update; update each EMA once per optimizer update with new-sample weight 0.01. Inputs and gamma are from that update's pre-step forward pass. Initialize EMAs at zero and bias-correct with 1−0.99^n.

$$
c=\frac{\operatorname{EMA}_{bc}(\|h\odot\gamma\|^2/r(h))}{\operatorname{EMA}_{bc}(\|h\odot\gamma\|^2)+10^{-12}}.
$$

After optimizer update 763, freeze c and copy the then-current gamma into gamma-tilde. Gamma-tilde has no optimizer state before activation: skip its inactive branch rather than accumulating zero-gradient Adam steps. Its first Adam step is update 764. Preserve gamma's existing state. Keep inactive parameters out of optimizer updates at endpoints; zero-decay gamma is inactive after gate zero. Save all state for reproducibility.

For u≤763 use g=1; for 763<u<6,104 use the equation below; for u≥6,104 use g=0.

$$
g(u)=\tfrac12\left[1+\cos\left(\pi\frac{u-763}{5341}\right)\right].
$$

Gamma-tilde remains trainable after calibration. At zero gate skip token-dependent norm computation at internal sites. Fold scalings only in a separate inference equivalence check; training retains explicit parameterization.

## Optional auxiliary condition

For Taper-plus, collect an EMA of mean pre-final-norm residual RMS during the same 763-update warmup, then freeze its bias-corrected value as s-target.

Explicit convention: auxiliary coefficient is zero during warmup; activate 0.1 beginning at update 764 after a fixed target exists:

$$
L_{train}=L_{CE}+0.1\,\mathbb E_{b,t}(r(h_L)-s_{target})^2.
$$

This onset convention and optimizer endpoint behavior must be documented as implementation choices, not claimed as an exact replication of unspecified paper code. All reported evaluation losses are CE alone.

## Run allocation and order

Before inspecting training outcomes, benchmark and choose primary only or primary plus all three auxiliary seed groups. No one-seed auxiliary claim. Lock the allocation in the manifest.

Run primary seeds in order 101, 102, 103; within each seed use RMS prefix, its web/code branches, then Taper-minus prefix and its web/code branches. Run optional auxiliary groups afterward, in the same seed order. A cost overrun leaves these incomplete and exploratory; do not selectively retain favorable secondary seeds.

Remove the v2 early look and seeds 104–105 extension. Stop only for data/correctness/numerical failure, resource exhaustion or explicit user direction. An interim promising or disappointing curve is not a stopping criterion.

## Validity gates

Data and code checks must pass before scientific runs. For primary runs, require absolute relative pre-switch web CE gap ≤2% and each code branch to improve non-whitespace code CE by ≥0.05 nats from its own prefix.

A 2–5% prefix gap is a comparability warning; >5% is a severe comparability failure. Neither automatically proves a software bug. Keep and report all completed results. Nonfinite losses are numerical failures and invalidate a clean H1 interpretation. Diagnose before rerunning, with every attempt charged to the cap.

These guardrails limit interpretation; they are not post-hoc seed exclusion rules. Auxiliary comparability is assessed separately and cannot erase a valid primary outcome.

## Departures and limitations

The paper's operator is reused; this is not an exact paper replication. C4/Python, GPT-2 tokenizer, GELU, learned positions, nonzero matrix decay, LR schedule, gate end at 40%, aux onset and domain branching are this study's choices.

Embeddings dominate the parameter count; differential embedding drift can mediate or interact with the condition effect, not merely dilute it. The model is a small finite-budget pilot, with no convergence claim. Generalization beyond this corpus sample, scale and training recipe is untested.
